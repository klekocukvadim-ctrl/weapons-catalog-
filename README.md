# Каталог стрілецької зброї

Мобільний енциклопедичний довідник українською мовою. Лише відкриті матеріали Вікіпедії та світлини Wikimedia Commons. Не містить інструкцій із виготовлення, модифікації чи застосування зброї.

Статичний сайт (HTML/CSS/JS, PWA) без кроку збірки. Каталог розгортається на Render як static site з `staticPublishPath: ./`.
